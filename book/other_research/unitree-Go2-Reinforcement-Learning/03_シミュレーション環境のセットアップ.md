# 3. シミュレーション環境のセットアップ

## 概要

この章では，Unitree Go2の強化学習結果を用いて，シミュレーター環境上でUnitree Go2を動作させるための環境構築手順について記述する．

## 前提条件

ノートPC（Ubuntu 24.04）で動作を確認した．

## 理論背景

Isaac Sim上で学習した，強化学習済みの方策を，MuJoCo(別のシミュレーター環境)上で動作させることで，コントローラーを通じてGo2に入力を行い，その挙動を確認することができる．これにより，実機上での動作確認を行う前に，シミュレーター上で挙動を確認することができる．

### インストールするソフトウェア

#### unitree_sdk2

unitree_sdk2は，Unitree製品の制御用SDKである．C++版とPython版があり，MuJoCo上でGo2を動作させるためにはC++版を使用する．

#### MuJoCo

MuJoCoは，物理演算エンジンであり，主に関節構造のロボットの挙動を高速にシミュレーションすることができる．

#### unitree_mujoco

unitree_mujocoは，unitree_sdk2と，MuJoCoを組み合わせて開発されたシミュレーター．SDK側で開発したシステムを，MuJoCoのシミュレーター上，実環境上でシームレスに動作させることができる．

## 環境構築の実施

強化学習終了後にUnitree Go2を，シミュレーター上で動作検証を行うための環境を整備する．

手順は，unitree_rl_labリポジトリのdeployに関する説明を参考にしている．

[https://github.com/unitreerobotics/unitree_rl_lab](https://github.com/unitreerobotics/unitree_rl_lab)

## 実装例


### unitree_sdk2・unitree_rl_labの導入

1. 必要モジュールのインストール

```bash
sudo apt update
sudo apt install -y build-essential cmake \
  libyaml-cpp-dev libboost-all-dev libeigen3-dev libspdlog-dev libfmt-dev
```

2. unitree_sdk2（C++版）のインストールとビルド

```bash
# Install unitree_sdk2
git clone https://github.com/unitreerobotics/unitree_sdk2.git
cd unitree_sdk2
mkdir build && cd build
cmake .. -DBUILD_EXAMPLES=OFF
sudo make install
```

3. ノートPCにもunitree_rl_labをクローンする．なお，ノートPCでは強化学習を実行しないため，Pythonモジュールのインストールは不要である．

```bash
cd ~/workspace
git clone https://github.com/unitreerobotics/unitree_rl_lab
```

4. onnxruntimeの共有ライブラリへのシンボリックリンクを作成する

```bash
cd ~/workspace/unitree_rl_lab/deploy/thirdparty/onnxruntime-linux-x64-1.22.0/lib
ln -s libonnxruntime.so.1.22.0 libonnxruntime.so
```

### go2_ctrl（コントローラー）のビルド

```bash
cd ~/workspace/unitree_rl_lab/deploy/robots/go2
mkdir build && cd build
cmake ..
make
```

以下のような出力が出れば成功

```bash
[100%] Built target go2_ctrl
```

これにより，go2_ctrlファイルが生成される．

### unitree_mujocoのビルド

ここからはMuJoCoの設定を行う．手順はunitree_mujocoのリポジトリを参考にしている．

[https://github.com/unitreerobotics/unitree_mujoco](https://github.com/unitreerobotics/unitree_mujoco)

1. MuJoCo側の必要パッケージをインストール

```bash
sudo apt install -y libglfw3-dev
```

2. ~/.mujocoというフォルダを作成し，MuJoCo本体をダウンロード（unitree_mujocoのリポジトリにはMuJoCo本体が含まれていないため，別途ダウンロードする）

```bash
cd ~
mkdir -p .mujoco && cd .mujoco
wget https://github.com/google-deepmind/mujoco/releases/download/3.3.6/mujoco-3.3.6-linux-x86_64.tar.gz
tar xzf mujoco-3.3.6-linux-x86_64.tar.gz
```

3. unitree_mujocoのリポジトリをクローンする

```bash
cd ~/workspace
git clone https://github.com/unitreerobotics/unitree_mujoco
```

4. MuJoCo本体へのシンボリックリンクを作成

```bash
cd ~/workspace/unitree_mujoco/simulate/
ln -s ~/.mujoco/mujoco-3.3.6 mujoco
```

5. シミュレーターのビルド

```bash
cd ~/workspace/unitree_mujoco/simulate/
mkdir build
cd build
cmake ..
make -j4
```

以下のような出力が出れば成功

```bash
[100%] Built target unitree_mujoco
```

これにより，unitree_mujocoファイルが生成される．

以上で，MuJoCoシミュレーターのビルドが完了する．

### unitree_mujocoの設定（config.yaml）

以下のように設定を変更する
(~/workspace/unitree_mujoco/simulate/config.yaml)
```yaml
robot: "go2"  # Robot name, "go2", "b2", "b2w", "h1", "go2w", "g1", "h2", "as2"
robot_scene: "scene.xml" # Robot scene, /unitree_robots/[robot]/scene.xml 

# ↓を1から0に変更
domain_id: 0  # Domain id
interface: "lo" # Interface 
# DDS IDL type: -1 auto, 0 unitree_go, 1 unitree_hg. Auto selects unitree_hg for as2.
idl_type: -1

# ↓を0から1に変更
use_joystick: 1 # Simulate Unitree WirelessController using a gamepad
joystick_type: "xbox" # support "xbox" and "switch" gamepad layout
joystick_device: "/dev/input/js0" # Device path
joystick_bits: 16 # Some game controllers may only have 8-bit accuracy

print_scene_information: 1 # Print link, joint and sensors information of robot

enable_elastic_band: 0 # Virtual spring band, used for lifting h1
```
